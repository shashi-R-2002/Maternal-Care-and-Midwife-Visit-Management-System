# 🤱 Maternal Care and Midwife Visit Management System

A web-based system to manage maternal care, midwife assignments, and home visit schedules efficiently. Developed using Laravel.

### ✨ Key Features
- 👩‍⚕️ Midwife Management - Add, manage midwives and their assigned areas
- 🤰 Mother Registration - Register pregnant mothers and maintain health records
- 📅 Visit Scheduling - Schedule and track home visits by midwives
- 📊 Dashboard & Reports - View visit history and upcoming schedules
- 🔐 Secure Authentication - Role-based login system

### 🛠️ Tech Stack
- **Backend:** Laravel 10
- **Frontend:** Blade, Tailwind CSS / Bootstrap, Vite
- **Database:** MySQL
- **Language:** PHP 8.1

### 🚀 How to Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/shashi-R-2002/Maternal-Care-and-Midwife-Visit-Management-System.git
```

**2. Install dependencies**
```bash
composer install
npm install
npm run dev
```

**3. Setup environment**
```bash
cp .env.example .env
php artisan key:generate
```

**4. Create database and run migration**
```bash
php artisan migrate
```

**5. Start the server**
```bash
php artisan serve
```
